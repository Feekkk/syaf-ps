# Syaf - personal shopper web apps

A one-person shop for bags, shoes, ready-to-wear, and accessories. Pieces are bought in person, checked against the maker’s marks, and photographed as they are, wear included.

The site is the shop window. It shows what is in stock this drop. Requests for pieces that are not listed go through WhatsApp.

## The drop

Enquire opens TikTok. Contact on the page is TikTok only (@syafwaldorf).

## Buying

Syaf finds a named piece, photographs it, and waits for a yes before buying. Payment is due before the piece leaves. If it cannot be found, there is no fee. That is written on the page as FAQ.

## Contact

TikTok sits at the close of the page. Letters, questions, and photographs of things you are hunting for are welcome.
